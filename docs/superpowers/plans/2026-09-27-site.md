# The M&A Companion Implementation Plan

> For agentic workers: use Superpowers executing-plans for integration, TDD for behavior, parallel isolated editorial tasks, and a final independent review.

**Goal:** Deliver a usable free source-linked course and reference site.
**Architecture:** Build-time evidence imports, authored content collections and static Astro routes. No raw inputs in public output.
**Tech Stack:** Astro, TypeScript, Pagefind, custom CSS, Node tests and browser QA.
**Spec:** docs/superpowers/specs/2026-09-27-site-design.md

## Global constraints
- All corpus and research files remain read-only.
- Public output contains no local source paths, raw transcripts or private supporting-context fields.
- 117 videos, 313 quantitative references and 28 provider records remain traceable.
- Canonical domain is configurable and initially unset; no public deployment.
- Plain original educational prose; source confidence and deal status preserved.

## Review focus
- Mixed native/Whisper evidence must preserve aligned provenance and lower confidence.
- Missing canonical, offline build and unavailable localStorage must degrade safely.
- Literal pipes/quotes and uncommon video IDs must not break import or links.
- Numerical illustrations, forecasts and reported transactions must not become general facts.
- Mobile navigation, large tables and filtered empty states must remain usable.
